# agcl

Short name for [AgentCollar](https://www.npmjs.com/package/agentcollar):

```bash
npx agcl        # same as: npx agentcollar
```

If you install AgentCollar itself (`npm install -g agentcollar`), the `agcl` command comes with it,
so you do not need this package. It only reserves the name, so nobody else can publish a package
called `agcl` that runs different code.
