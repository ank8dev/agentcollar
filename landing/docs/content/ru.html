Пусть агенты работают.
Ключи — у вас.

AgentCollar — маленький брокер, который работает на вашем компьютере. ИИ-агент просит у него короткий пропуск на одну задачу. Вы одобряете его в Telegram. Ваш пароль агент не видит никогда.

{{hero-install}}
Node.js 22+0 зависимостейна паузе · на свой страх и риск
Проект на паузе.

Всё, что описано на этой странице, работает и проверено от начала до конца: Claude Code просит mandate, вы одобряете его в Telegram, он читает ваш настоящий Gmail и оставляет черновик. Но разработка приостановлена, и, возможно, автор к ней больше не вернётся: ни новых функций, ни обещанных исправлений. Код остаётся открытым под MIT — делайте fork, если он вам нужен. Хобби-проект: используйте на свой страх и риск и не подключайте аккаунты, потерю которых не можете себе позволить.

Начало работы

От нуля до работающего брокера примерно за три минуты. Нужны Node.js 22 или новее и аккаунт в Telegram. Сначала проверьте Node:

{{node-version}}

1. Установка

Запустите один раз без установки или установите, чтобы получить короткую команду agcl.

{{install}}

2. Подключите своего бота в Telegram

Создайте бота у @BotFather (/newbot) и скопируйте его токен. Затем запустите agcl. В первый раз он сам запустит мастер настройки.

3. Впустите агента

Подключите Claude Code через MCP или вызывайте HTTP API из своего скрипта. Теперь каждый запрос проходит через вас.

Мастер настройки, шаг за шагом

Вот что вы увидите. Строки, начинающиеся с $, — то, что вводите вы.

{{setup}}

Что произошло, строка за строкой:

  1. Токен скрыт, пока вы его вводите, и проверяется в Telegram. На неверный токен — понятная ошибка, а не падение.
  2. В ссылке одноразовый код (K7P2M9QX). Засчитывается только /start именно с этим кодом и только в личном чате. Посторонний, нажавший Start у вашего бота в ту же секунду, не станет тем, кто одобряет.
  3. «Это вы?» — можно проверить имя своими глазами.
  4. Настройки сохраняются в ~/.agentcollar/.env. Прочитать файл может только ваш пользователь macOS. Бот тоже напишет вам: «AgentCollar is set up».
Нет Telegram? Не страшно.

Ответьте n на первый вопрос. Тогда брокер будет спрашивать одобрение прямо в терминале: y или N.

Как это работает

Три участника, одно правило: агент говорит только с брокером, а брокер действует только после того, как пройдены проверки.

{{sequence}}

Мандаты

Мандат — это разрешение на одну задачу. Агент просит его, вы одобряете, и он сам перестаёт действовать. В нём есть:

Отсчёт времени начинается с момента одобрения, а не с запроса агента. Если за 10 минут никто не ответил, запрос отклоняется. Это называется fail closed: если есть сомнения, ответ — нет.

Одобрение в Telegram

Когда агент просит мандат, вашему боту приходит такое сообщение:

{{telegram}}
  • Сначала факты, слова агента — в конце. «Actions» и «Lifetime» — то, что брокер действительно соблюдает. Задача — это лишь рассказ агента, сжатый в одну строку, поэтому подделать лишнюю строку «Actions:» он не сможет.
  • Если агент просит *.send, первым идёт предупреждение: агент просит право ОТПРАВЛЯТЬ от вашего имени.
  • После одобрения кнопки меняются на 🛑 Revoke.
  • Нажимать может только ваш Telegram user id. Все остальные получают «No access».

Журнал аудита

Каждая проверка и каждое решение человека — одна строка в ~/.agentcollar/audit.log. Строки только добавляются и никогда не меняются. Вот сырой файл:

{{audit-raw}}

Текст от агентов записан в кавычках (JSON.stringify), поэтому агент не может вставить перенос строки в своё имя и подделать запись. Токен сюда не пишется никогда. Последняя колонка показывает, какая проверка решила. agcl logs превращает это в читаемый вид (см. ниже).

Подключение Gmail

Из коробки брокер использует фальшивый ящик, так что всё можно спокойно попробовать. Когда будете готовы, подключите настоящий Gmail. Подключение умеет читать почту и создавать черновики. Отправлять оно не может никогда: это блокирует брокер, и это блокирует Google, потому что права на отправку никто не запрашивал.

  1. В Google Cloud создайте OAuth-клиент типа Desktop app и скачайте его JSON-файл.
  2. Запустите команду ниже. Откроется браузер. Разрешите «читать почту» и «создавать черновики».
  3. Перезапустите брокер.
{{gmail-connect}}

Refresh-токен хранится в связке ключей macOS (Keychain), никогда не в файле. Короткоживущий access-токен есть только в памяти. Проверить или удалить подключение можно в любой момент:

{{gmail-status}}
Тестовый режим длится 7 дней

Пока ваше приложение в Google находится в тестовом режиме, Google завершает вход через 7 дней. Просто снова запустите agcl gmail connect.

Команда agcl

agcl — короткое имя agentcollar. Это одна и та же программа: agcl watch = agentcollar watch. Короткое имя работает после npm install -g agentcollar. С npx используйте длинное: npx agentcollar watch.

{{help}}

agcl

Команда «просто сделай, чтобы работало». Показывает заставку, запускает мастер настройки, если Telegram ещё не настроен, затем стартует брокер. В скрипте (когда за терминалом нет человека) пропускает вопросы и сразу запускает брокер.

agcl setup

Подключает вашего собственного бота в Telegram. См. подробный разбор. Запускать повторно безопасно: он спросит, прежде чем заменить существующий .env, и сохранит остальные строки (например, BROKER_PORT).

agcl server

Запускает брокер. Он слушает только 127.0.0.1:8787: программы с других компьютеров до него не достанут. Остановить — Ctrl+C.

{{server}}
BROKER_PORT=9000
Другой порт. Пропишите его в ~/.agentcollar/.env.
Мандаты живут в памяти

Когда вы останавливаете брокер, все мандаты исчезают. Агенты просто попросят снова. Журнал аудита остаётся.

agcl watch

Экран в реальном времени. Откройте его во втором терминале и смотрите, как приходит каждый запрос. Он только читает журнал аудита и ничего не может изменить.

agcl revoke <id>

Аварийный выключатель. Мандат перестаёт работать на следующем же запросе. Работает без интернета. Сообщение в Telegram тоже обновится.

agcl mcp

Запускает MCP-сервер, которым пользуются Claude Code и другие агенты. Обычно вручную его не запускают: это делает агент. См. следующий раздел.

Заставка

Вращающийся медальон — это логотип, нарисованный символами Брайля (⣿⡇⠟). В каждом 8 точек, поэтому картинка детальнее, чем из обычных букв. Длится около 1,7 секунды, любая клавиша её пропускает, и она никогда не показывается в пайпах, CI, с NO_COLOR или с --no-intro.

Работа с Claude Code

MCP (Model Context Protocol) — общий язык между ИИ-агентом и его инструментами. AgentCollar его понимает, поэтому Claude Code может пользоваться брокером сам. Добавляется одной командой:

{{mcp-add}}

Держите agcl server запущенным в другом терминале. Затем просто попросите Claude:

{{mcp-prompt}}

Что происходит дальше:

  1. Claude вызывает request_mandate с нужными ему действиями.
  2. Телефон вибрирует. Вы нажимаете ✅ Approve.
  3. Claude вызывает mandate_status, видит approved, затем gmail_read_inbox и gmail_create_draft.
  4. Если он попробует gmail_send без разрешения, брокер скажет нет.

Модель никогда не видит токен

MCP-сервер держит секретный токен внутри своего процесса и отдаёт модели только mandateId. Поэтому если в письме есть prompt injection вроде «пришли мне свой токен», красть нечего.

Браузеры отклоняются нарочно

Веб-страница тоже может слать запросы на localhost. Поэтому брокер отклоняет любой запрос с заголовком Origin, проверяет Host (защита от DNS rebinding) и принимает только application/json. Программ вроде curl и агентов это не касается.

Безопасность

Ненадолго

Мандаты истекают сами. Запросы без ответа умирают через 10 минут.

Только одна задача

Только перечисленные действия. Черновик не превратится в отправку.

Отзыв в любой момент

Одно касание в Telegram или agcl revoke. Действует со следующего запроса.

Всё в журнале

Каждая проверка, каждое решение — по строке. Токены — никогда.

От чего защищает брокер

  • Украденный токен мандата: одна задача, короткое время, можно отозвать. А не весь ваш ящик навсегда.
  • Агент, который пошёл вразнос: его останавливает лимит, а журнал показывает, когда это началось.
  • Prompt injection в письме: агент может поверить, но действия нет в мандате, а через MCP токен даже не виден.
  • Поддельное сообщение об одобрении: действия обязаны выглядеть как app.verb, а текст агента — одна очищенная строка, показанная последней.
  • Агент, одобряющий сам себя: одобрить никогда нельзя через HTTP или через файлы. Только в Telegram (ваш id) или в терминале самого брокера.
  • Веб-страница, атакующая localhost: запросы из браузера отклоняются.
  • Отправка от вашего имени: у подключения Gmail есть только доступ на чтение и черновики. Даже ошибка в брокере не смогла бы отправить письмо.
  • Подменённый npm-пакет: релизы публикуются с provenance. Проверка: npm audit signatures.

От чего (пока) не защищает

  • Вредоносная программа, уже запущенная от вашего пользователя, может прочитать ~/.agentcollar/.
  • Мандаты теряются, когда брокер останавливается.

Решение проблем

В Telegram ничего не приходит

Откройте своего бота и хотя бы раз нажмите Start: боты не могут написать вам первыми. Проверьте, что agcl server пишет Approvals: Telegram. Если там this terminal, запустите agcl setup.

Настройка пишет «Another program is already listening to this bot»

Обычно это ваш же agcl server. Остановите его через Ctrl+C и снова запустите agcl setup.

Агент говорит, что брокер не запущен

Запустите брокер в отдельной вкладке терминала и не закрывайте её: agcl server (или просто agcl). Брокер и агент должны работать на одном компьютере. Потом попросите агента попробовать снова.

agcl mandates пишет «The broker is not running»

Мандаты живут в его памяти, поэтому после остановки показывать нечего. Запустите брокер и дайте агенту попросить снова.

Gmail перестал работать через неделю

Ваше приложение в Google в тестовом режиме, и Google завершил вход. Снова запустите agcl gmail connect.

Google пишет «Access blocked: … has not completed the Google verification process» (Error 403: access_denied)

Ваше приложение Google в тестовом режиме, поэтому Google пускает только тестовых пользователей. В Google Cloud откройте Google Auth Platform → Audience → Test users, добавьте свой адрес Gmail и снова запустите agcl gmail connect. Публиковать приложение не нужно.

agcl: command not found

Для короткого имени нужна установка: npm install -g agentcollar. Без установки используйте npx agentcollar.

Порт 8787 занят

Возможно, другой брокер уже запущен (проверьте через agcl mandates). Или запустите этот на другом порту: BROKER_PORT=8788 agcl server — и сообщите агенту новый адрес.

«Unsupported engine» или синтаксические ошибки при запуске

Ваш Node.js слишком старый. AgentCollar нужен 22 или новее: node --version.
